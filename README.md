# Data Grokr Week 2 - OOP Bank Account + Pandas Dataset Analysis

## Description

This project is a Python-based Bank Account Management System combined with Pandas and NumPy dataset analysis.

 It demonstrates Python programming concepts including Object-Oriented Programming, inheritance, polymorphism, decorators, context managers, exception handling, functional programming, modules, packages, virtual environments, Pandas, and NumPy.

## Features

- Create Savings and Current bank accounts
- Deposit money
- Withdraw money
- Savings account minimum balance validation
- Current account overdraft support
- View individual account details
- View all created accounts
- Transaction logging
- Transaction summary using Pandas
- Customer summary using Pandas
- Branch-wise transaction analysis
- NumPy statistical analysis
- High-value transaction filtering
- High-value customer filtering
- Account-type statistics
- Top customer analysis
- Sorted transaction analysis
- Exception handling for invalid operations
